# Data provenance

This `data/` corpus is the fictional **HelixPay** snapshot from the Codos take-home,
vendored from the task repo `github.com/opencodos/test-task` into this submission repo
(`github.com/teionarr/cds-house-harness`) so the engine is self-contained and runnable
with no runtime fetch.

To refresh from upstream: clone `opencodos/test-task` and copy its `data/` over this one,
then re-ingest (only changed files are re-processed — see ingestion notes in SOLUTION.md).
