# CLAUDE.md

Norms, commands, gotchas, and the development flow live in **`AGENTS.md`** — read it first.

This repo is built with a four-file external-memory loop: **AGENTS.md** (norms),
**PLAN.md** (checklist + definition of done), **PROGRESS.md** (running log),
**VERIFY.md** (exact commands that prove it works). Each session: read `PROGRESS.md`,
take the next item in `PLAN.md`, implement, run `VERIFY.md`, log to `PROGRESS.md`,
check off `PLAN.md`. See `AGENTS.md` → "Development flow" for the full loop.

Design doc: `BUILD_PLAN_HELIXPAY.md`. Submission narrative: `SOLUTION.md`.
